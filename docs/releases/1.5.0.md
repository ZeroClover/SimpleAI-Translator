- 修复恢复历史记录后，下一次提交可能没有反应的问题；重复提交相同内容仍可使用已有翻译缓存。
- 使用输入法按回车确认候选词时不再误触发翻译；Shift+Enter 仍用于换行。
- 流式译文改为合并刷新，减少长文本翻译时的界面更新；结束时立即显示完整结果，翻译失败时保留已收到的部分译文。
- 修复桌面端快速取消或替换翻译时的请求监听问题，避免旧请求干扰新结果；连接失败时能正常结束加载并显示错误。
- 浏览器扩展与后台连接断开时会结束请求并显示错误，不再一直等待响应。
- 桌面端支持带自定义端口的服务地址，可用于本地或自托管服务的模型列表刷新与请求。
- 保存设置时先写入完整的新配置再替换原文件，降低写入中断造成配置损坏的风险；启动时遇到损坏的配置会保留 .corrupted 备份并恢复默认设置，需要重新配置 Provider。
- 在线语言检测返回空结果、不支持的语言或 HTTP 错误时改用本地检测，不再直接将原文当作英语。
- Edge 朗读失败或音频解码失败后会释放音频资源，避免后续朗读受到残留播放状态影响。
- 切换背景模糊或主题时先清除旧窗口效果，避免模糊效果叠加。
- 桌面端等待下一次更新检查时不再占用异步工作线程。
- Linux 托盘的 Quit 改为直接退出应用；Windows 检测或创建 WebView 失败时新增原生错误提示，并提供 WebView2 安装或修复入口。
